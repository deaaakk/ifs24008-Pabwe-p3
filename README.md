# Trio Digital — Studi Kasus PABWE Praktikum 3

Aplikasi satu halaman dengan 3 tab:

1. **DompetKu** — Catatan Pengeluaran Harian (CRUD, ringkasan saldo, cari/filter/sort, localStorage)
2. **LinkVault** — Bookmark / Link Manager (CRUD, validasi URL, cari/sort, localStorage)
3. **KuisKilat** — Kuis Interaktif (5 soal, skor, timer per soal, high score localStorage)

## Cara menjalankan
Buka `index.html` langsung di browser (tidak perlu server/backend).

## Struktur
```
├── index.html
├── assets/
│   └── script.js
└── README.md
```
